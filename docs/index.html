AWS Workshop 等級補齊標準

  • 先備條件：AWS/GitHub/CLI/Domain 明確列出。
  • 實作 Lab：每個 Lab 有目標、步驟、命令、Expected output。
  • 驗收：API smoke、frontend build、production health、成本 cap 都有檢查點。
  • 安全：公開文件不含 secret，token 走 SSM，交接後輪替。
  • 排錯：用決策樹處理 DNS/TLS/502/API/429/Bedrock 權限。
