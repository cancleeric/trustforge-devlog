Live Demo 流程

一鍵啟動

PYTHONPATH=src python3 -m trustforge.cli analyze --coin BTC --query '分析 BTC 過去兩週市場狀況' --type multi_source --offline --out /tmp/trustforge-demo --quiet

輸入幣種代碼與查詢後，offline demo 可在數秒內完成；live / Bedrock 模式以 15 分鐘內產出三件主要輸出為硬限制。

完整執行流程（以 BTC 為例）

[00:00] Phase 1: Ingestion（多源平行抓取）
  ├── prices.py     → HOYA BIT 5年 BTC Daily OHLCV
  ├── coingecko.py  → 即時價格、市值、24h 變化
  ├── news.py       → RSS 抓取近期 BTC 相關新聞
  ├── social.py     → 社群情緒快照
  ├── onchain.py    → 鏈上活躍地址/大額轉帳
  └── regulatory.py → 監管動態
  → 輸出：50~200 條 Document

[01:00] Phase 2: Trust Layer
  Step 1: Claim 抽取（Bedrock #1）→ 100~400 條 Claim
  Step 2: 信任評分（確定性公式 + W1.5 Stance + W2 動態信譽 + W3 協同偵測）
  Step 3: 聚合 → TrustedBrief（supporting/contrarian/校準信心/三態判定）

[05:00] Phase 3: Agent（行文 + 複審）
  Step 3: Bedrock #2 — 帶溯源行文（強制引用 claim_id）
  Step 4: Bedrock #3 — 限制複審（審查合規）

[08:00] Phase 4: 輸出
  out/BTC/
  ├── report.md          ← 帶溯源鏈分析報告
  ├── evidence.json      ← 結構化證據清單
  └── execution_log.jsonl ← 完整執行紀錄

[00:02] Offline Demo Complete（本機實測約 2 秒；live / Bedrock 展示仍以 < 15 分鐘為硬限）

報告結構（report.md）

  • 摘要：帶溯源的結論（每個判斷標記 [claim_id]）
  • 支撐證據表：來源 / 信任分 / 摘要
  • 反方證據表：明確的反方觀點（不是垃圾）
  • 跨源訊號：客觀數據 vs 情緒訊號背離警示
  • 限制聲明：不構成投資建議 + 校準信心說明

證據清單結構（evidence.json）

每條包含：claim_id / source / kind / trust / trust_components（四分項細分）/ source_url / fetched_at / flags / info_flags。完整可溯源、可審計。

Demo 核心訊息

「不是把 Bedrock 當成答題機器，而是把它當成行文工具——判斷邏輯是我們自己的 pipeline 做的，LLM 只是幫我們把結果說得更好讀。」

這是 TrustForge 跟「直接問 ChatGPT/Claude 幫我分析 BTC」最本質的差異。
