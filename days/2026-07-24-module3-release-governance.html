工程意義

本輪重點不是單一功能，而是 TrustForge 從「核心可信推理」走向「可被使用者看見的解釋型產品面」。Peer Metrics、EcoLink、Asset Context 與 Glossary 讓使用者能看見同業比較、依賴／升級影響路徑、資產背景與風險說明；同時每個 read-only／illustrative guard 都在提醒：目前能呈現脈絡，不等於已經能把所有資料當正式評分 Evidence。

另一個工程意義是 release governance 更成熟。v0.18.1 把多條功能線、治理線與測試線合併到主線，但仍保留 sandbox、人類 activation、rollback、public schema whitelist 等安全收斂點。這符合 TrustForge continuous analysis skill 的原則：歷史記憶與學習可以輔助診斷，但不能自動改 Trust 權重、模型或正式報告。
