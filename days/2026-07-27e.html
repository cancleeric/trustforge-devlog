配色設計原則：操縱紅旗用 tf-bad 紅色（已反映在信任分扣分）；相似簇用 tf-accent 藍色（中性資訊，提醒但不指控）；跨源訊號：綠=共識 / 黃=背離 / 灰=未判定。紅旗和相似簇的配色刻意不同——避免使用者把「中性資訊提示」誤讀成「操縱判定」。

⚠️ 跨源背離：客觀數據（ETF 資金流入、機構增持）方向與情緒訊號（鏈上流出、恐慌指數飆升）方向不一致。建議讀者注意此分歧。

設計細節

  • Bullish 側：綠色邊框 + 淺綠底；Bearish 側：紅色邊框 + 淺紅底
  • 每個 stance pair 顯示來源名稱 + 原文摘要
  • 底部附 claim_id → 可追溯到 EvidenceTable 完整細節
  • 共識時：顯示綠底「共識」徽章，不拆左右欄
  • 單源主導時：額外顯示黃色 SingleSourceBadge 警示
  • stance pairs 經 groupByStance() 去重（同一 publisher 多條 claim 不重複列出）

Badge 視覺指標系統

Badge 配色 觸發條件 語意
🚩 暴漲、穩賺 tf-bad 紅 操縱關鍵詞命中 已扣分，hover 顯示命中哪些詞
ℹ 相似簇 tf-accent 藍 多源 Jaccard ≥ 0.8 且 ≥3 來源 informational，不扣分，中性提示供判讀
⚠️ 低信任/操縱 tf-bad 紅 trust < 0.3 整行淺紅背景 + badge
單源 tf-warn 黃 某維度僅 1 來源支撐 缺乏跨源互證，參考性較低
即時 紫 kind = price_live / onchain 資料類型層級標記

層次四：信任拆解（TrustBreakdown）

TrustBreakdown.tsx — 四維度 progress bar + WHY 文案：

信任拆解（逐項 WHY）

信譽80%

來源過去的可靠表現與跨來源核對結果

交叉佐證100%

彼此獨立的來源是否支持同一主張

資料時效45%

資料距離現在的時間與更新狀態

操縱風險15%

命中操縱訊號的比例，越低越好（反向指標）

反向配色邏輯：操縱風險維度的配色與其他三項相反——分數高 = 壞（紅色），分數低 = 好（綠色）。其他三項：≥60% 綠 / ≥35% 黃 / <35% 紅。如果某維度尚無評分，顯示「暫無評分」灰色文字，不填 0 假裝安全。

層次五：決策態徽章

報告最頂層方向結論旁，一定附著決策態徽章（DecisionStateBadge）：

正常判斷 calibrated ≥ 0.50
資訊完整度偏低 0.35 ≤ calibrated < 0.50
棄權／資料不足 calibrated < 0.35 或獨立來源 < 2

使用者不用看完所有證據細節，光看這個 badge 就知道：這份報告對自己的結論有多少信心。

UX 設計哲學

原則 實作方式 對使用者的價值
漸進式揭露 概覽 → 面板 → 逐條展開 → 四維拆解 各層深度可停，不強迫資訊過載
配色即語意 紅=操縱已扣分 / 藍=中性提示 / 黃=警示 / 綠=共識 不用讀文字就知道嚴重程度
不造假 缺評分顯示「暫無」；未判定顯灰色中性態 「未知」和「安全」永遠能區分
溯源可點擊 結論 → claim_id → Evidence 展開 → 原始 URL 每個判斷都能驗證
反方不是垃圾 contrarian 與 supporting 同等規格呈現 使用者看到完整牌面，不被引導
